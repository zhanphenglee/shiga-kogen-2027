# Shiga Kogen 2027 🎿

Trip planning site for our ski trip to Shiga Kogen, Nagano — 2027 season. 12 of us.

**Live site:** https://zhanphenglee.github.io/shiga-kogen-2027/

## What's here

The whole site is one self-contained file:

- `index.html` — everything: Overview (interactive map), Stay, Transport, Itinerary, Food.
  Own styles and tab navigation inline, no build step, no framework. Open it directly in
  a browser to preview.

Deploys automatically to GitHub Pages on every push to `main`, via
`.github/workflows/pages.yml`.
